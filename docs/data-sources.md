## 八、补充说明

- **学会专委会**：各一级学会下设的专业委员会（如中国细胞生物学学会的「细胞器生物学分会」「免疫细胞分会」）也会独立办会，接入时可从学会官网「分支机构」页获取清单。
- **研究院/实验室**：如北京生命科学研究所（NIBS）、深圳湾实验室、昌平实验室、临港实验室、之江实验室等，常年举办前沿讲座/论坛。
- **企业学术活动**：药明康德、华大智造、百济神州、诺禾致源、燃石医学等企业官网常有学术论坛/峰会信息。

## 接入优先级建议

1. **第一批（学会，结构规范、易解析）**：中国遗传学会、中国植物学会、中国微生物学会、中华医学会、中国计算机学会、中国自动化学会、中科院各所。
2. **第二批（会议聚合站，量大）**：生物谷会议、丁香会议、中国学术会议在线。
3. **第三批（C9 高校，结构各异、逐校适配）**：优先 北大/清华/复旦/上交/浙大 的生命科学、医学、AI 学院通知页。
4. **第四批（流媒体，半自动）**：公众号/小红书/抖音 关键词监控 + 人工确认。
